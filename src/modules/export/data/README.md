# Bundled PDF map geometry

`countries-110m.js` is a source-bundled copy of World Atlas 2.0.2 `countries-110m.json`, derived from Natural Earth and licensed under the ISC license included beside it.

The asset is intentionally bundled with Atlas so itinerary PDF generation does not depend on Google Maps canvas capture, third-party CDNs, CORS, network availability, or browser storage at export time.
